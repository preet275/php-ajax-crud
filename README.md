# PHP & AJAX CRUD

A simple CRUD application built using PHP, MySQL, AJAX and jQuery.

## Features

- Add User
- Update User
- Delete User
- Live Search
- Pagination
- AJAX CRUD Operations
- Form Validation

## Technologies

- PHP
- MySQL
- AJAX
- jQuery
- HTML
- CSS

## Database

Database Name: `ajax`

Table Name: `user`

## How to Run

1. Put the project inside `htdocs`
2. Start Apache and MySQL from XAMPP
3. Create a database named `ajax`
4. Create the `user` table
5. Open the project in your browser
